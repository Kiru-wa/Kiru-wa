## 🧩 About Kiru

**Kiru** is an open-source ecosystem focused on building practical tools
for working with AI, applications and digital projects.

The goal is simple:

> **Make powerful tools feel simple.**

No unnecessary complexity.  
No forced ecosystem lock-in.  
Just useful software that belongs to you.

---

## 🚀 Projects

### 🖥️ Kiru Terminal
An AI-oriented terminal and workspace built around OpenRouter.
