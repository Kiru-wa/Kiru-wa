# 🚀 Kiru

> An open-source ecosystem of apps, tools and experiments.

Kiru is a collection of independent projects built under one ecosystem and visual identity.

The projects are not tied to a single purpose or technology. Some are development tools, some are utilities, and some are experiments for completely different tasks.

## 🧩 Projects

### 🖥️ Kiru Terminal

An AI-focused development and work environment.

Kiru Terminal is the project in the ecosystem most closely focused on AI.

Its goal is to make working with AI more convenient for development and everyday technical tasks, while gradually turning it into a more capable agent environment.

Currently focused on Windows, with Android planned for the future and Linux being considered.

The first version includes:

- 🤖 AI through OpenRouter
- 🌐 Web Search
- 📂 File analysis
- 📝 File creation
- ✏️ File editing
- `.txt`, `.json` and `.md` support

The architecture is designed to support other AI providers in the future.

🚧 In development.

### 📦 Kiru Another APK

An Android utility for working with different Android package and container formats.

Planned support includes:

`.apk` · `.xapk` · `.apkm` · `.apks` · `.aab` · `.obb` · `.zip`

This project is not centered around AI — it is a standalone utility for working with Android packages.

🚧 In development.

### 📥 Kiru Installer

A small installer and launcher for Kiru projects.

It will be able to:

- install Kiru applications
- check for updates
- download new releases
- update installed applications

GitHub Releases will be used for distribution, so Kiru doesn't need its own download server.

🚧 In development.

## 🖥️ Platforms

The Kiru ecosystem is primarily being developed for Windows.

Android support is planned for the future, allowing Kiru projects to expand beyond the desktop.

Linux is also being considered as a future platform.

The exact availability of each project may differ depending on its purpose and technical requirements.

The goal is to gradually make the Kiru ecosystem available across:

- 🪟 Windows
- 🤖 Android
- 🐧 Linux

## 🎨 Kiru Design

Although the projects have different purposes, they share a common visual identity.

The current design direction includes:

- Material Design 3
- Liquid Glass-inspired elements
- no background blur
- clean and minimal interfaces
- predominantly rectangular and square shapes
- slightly rounded corners
- custom hand-drawn icons

The goal is to make Kiru projects recognizable as parts of the same ecosystem without forcing every project to look or work the same way.

## 🛠️ Technology

Different Kiru projects may use different technologies depending on their purpose.

Kiru Terminal is being built with:

- Kotlin
- Compose Multiplatform

The technology stack is chosen according to the needs of each individual project rather than enforcing one stack on the entire ecosystem.

## 🔮 What's next?

Kiru is still at an early stage.

Future projects may cover completely different areas, from development utilities to Android tools and other experiments.

For Kiru Terminal specifically, the long-term roadmap may include:

- 🖥️ Terminal and command execution
- 📁 Advanced file system tools
- 🔀 Git and GitHub integration
- 🔌 MCP support
- 🌐 Advanced browser tools
- 🤖 Subagents
- 🧠 Multiple AI models working as a team
- 💻 Computer interaction
- 🔐 Advanced permissions and approvals
- 🛠️ AI-assisted development

These features are intentionally not being pushed into the first releases.

## 📜 Open Source

Kiru projects are intended to be free and open source.

Kiru is not built around a single centralized service or backend.

Each project can have its own architecture, dependencies and purpose while remaining part of the same ecosystem.
